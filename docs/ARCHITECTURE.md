# Архитектура и API

## Стек
Python 3.12, FastAPI/Uvicorn, PostgreSQL (psycopg), Docker Compose. Интерфейс — HTML/CSS/JavaScript. BeautifulSoup/lxml и requests используются при сборе публикаций. CTranslate2/SentencePiece — необязательный локальный перевод. Scikit-learn — экспериментальные модели и обучение.

## Поток данных
Запрос → коннекторы источников → нормализация, даты и тематическая фильтрация → кандидаты и цитаты → правила ранней стадии, ограниченного внедрения и релевантности → ранжирование → карточки и отчёт. Дубликаты и общее происхождение публикаций учитываются отдельно. Балл правил не является вероятностью.

Результаты записываются в runs/<run_id>. При заданном DATABASE_URL снимки также сохраняются в PostgreSQL. Compose подключает PostgreSQL автоматически и публикует приложение только на 127.0.0.1. Без базы используется файловое хранение.

## API
- GET /health — состояние хранилища.
- GET /api/runs — история заданий.
- GET /api/runs/{run_id}/view?translate_cards=false — карточки без ожидания перевода.
- GET /api/runs/{run_id}/view?candidate_id=ID — перевод выбранной карточки при наличии модели.
- POST /api/search — query, search_query, as_of (YYYY-MM-DD), search_mode (quick/extended).
- POST /api/review — сохранение результатов проверки.
- GET /runs/{run_id}/report.html — отчёт.
- /docs — Swagger с точными схемами API; /openapi.json — спецификация.

POST-запросы требуют X-Local-Token из страницы приложения. Это локальная защита, не полноценная авторизация для публичного многопользовательского сервиса. Внешнее развёртывание требует отдельной настройки доступа и HTTPS.

## Ограничения публичного пакета
Исходный XLSX, PDF задания, сохранённые полные тексты, веса моделей рейтинга и история запусков не опубликованы. Новый поиск доступен. Обучение на исходном датасете и тесты, использующие закрытые файлы, требуют их отдельного предоставления. Независимая оценка детекции не выполнена; подборка TOP-15 не подтверждена.
