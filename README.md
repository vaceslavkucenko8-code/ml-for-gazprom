# СИГНАЛ

Прототип поиска ранних технологических разработок для задачи Газпромбанк.Тех. Находит публикации, выделяет кандидатов и показывает цитаты, основания отбора и ограничения.

## Локальный запуск

Требуется Python 3.12. На Windows откройте **start.cmd**. При первой установке нужен интернет. Откройте http://127.0.0.1:8765/ и оставьте окно сервера открытым.

На macOS/Linux:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.local_app
```

На главной странице задайте тему, английскую формулировку при необходимости и дату оценки. Поиск требует интернета; результат может содержать менее 15 разработок или быть пустым. История сохраняется локально в runs.

### Docker и PostgreSQL

```sh
docker compose up -d --build
```

Откройте http://127.0.0.1:8766/ . Для остановки: `docker compose down`. Не добавляйте `-v`, если нужно сохранить базу. Первый запуск требует загрузки образов и зависимостей.

### Необязательный перевод

В активном Python-окружении выполните `python scripts/install_translation.py` (Windows: `.venv/Scripts/python.exe scripts/install_translation.py`). Для Docker после установки пересоберите контейнер. Без модели доступны оригинальные тексты и русские статусы. Перевод запускается кнопкой в карточке.

## Состав публикации и статус

Это публичный пакет кода и инструкций. Исходный XLSX, PDF задания, полные тексты собранных публикаций, модели рейтинга и сохранённые запуски остаются в локальном пакете команды. Презентация и внешний веб-стенд пока не опубликованы.

Полная локальная версия прошла 232 программных теста 28.09.2026. Это не оценка точности детекции. Независимая оценка на закрытой выборке организаторов не выполнена. Команда исследовала 12 разработок; это не 12 подтверждённых автоматических сигналов и не выполнение TOP-15. Балл правил — не вероятность.

В публичной версии запустите `python -m pytest tests -q`; проверки, требующие неопубликованных данных, явно пропускаются. Исторические результаты полной версии нельзя переносить на качество нового сетевого поиска.

GitHub содержит исходники; адрес 127.0.0.1 работает только на компьютере, где запущено приложение.
